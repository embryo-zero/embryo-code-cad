# Embryo Code CAD

Embryo Code CAD is Embryo-Zero's fork of [OpenSCAD](https://github.com/openscad/openscad) (e65a922, commit e65a922). It does 3D models from scripts.

- Our changes live on the `embryo` branch. The original license files (COPYING) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
